# CENTRUM UNIVERSI // FIELD TEST E-27

Shooter en primera persona. Versión **0.5.4 (beta)**.

## Descargar

En [Releases](https://github.com/radusquinho/centrum-universi/releases/latest), el `.zip` de Windows.

El `.zip` lleva contraseña: hace falta 7-Zip o WinRAR para abrirlo (el descompresor de Windows no puede). Descomprímelo y abre `CENTRUM.exe`, con `CENTRUM.pck` y las `.dll` en la misma carpeta. Para el multijugador, Steam abierto.
